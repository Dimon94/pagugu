# HostConfig 模块合同（L2）

模块职责: owns 三个 Agent Host 的调用面配置只读 adapter、通用宿主配置提交机制与 JSON key-path 写通道，以及 Claude Code/Codex/Pi 用户级写 adapter。Reader 结合 HostProfile 能力矩阵输出实时文件事实；通用 Writer 负责提交前漂移检测、原子替换与逐文件单槽备份/恢复；Claude adapter 集中映射四档；Codex adapter 集中映射三档并以行级最小修改保全 TOML/YAML 格式；Pi adapter 以独占文件本身为主张，原子写三档互斥名称集合。does not own Pi 扩展交付物生命周期、Visibility Claim 持久化、文件监听、Skill Identity、UI 呈现或其他持久状态。

成员清单:
- `HostConfigReader.swift`：`HostConfigReader.invocationSurfaces(skillName:installations:)` 是唯一宿主事实读取入口；`ExposureLevel` 与宿主支持矩阵由 repo://Pagugu/HostProfile/HostProfile.swift owns。
- `HostConfigWriter.swift`：`rewriteConfiguration(at:transform:)` 与 `rewriteConfigurations(at:transform:)` 向 adapter 提供单文件/单动作多文件完整字节变换 seam；nil 或相同字节零写入。多文件动作先读取并产出全部变换，再一次重读全部文件防漂移；未漂移才把动作涉及文件的原始状态写入单槽：现存文件快照到 `<file>.pagugu-backup`，缺失文件以 `<file>.pagugu-backup-missing` 标记；随后逐文件原子替换目标，使恢复槽属于同一动作。`merge(_:at:in:)` 复用单文件 seam 增删 JSON 叶子；删除路径不存在时零写入，不创建空中间对象或备份槽。`restoreBackup(for:)` / `restoreBackups(for:)` 原子覆盖原字节或删除由 Pagugu 创建的目标，并保留备份状态；`claimState(expecting:at:in:)` 实时派生 JSON key 一致/分歧。
- `ClaudeConfigWriter.swift`：唯一 Claude Code 写 adapter。`apply(exposureLevel:forSkillNamed:installations:)` 只写用户级 `~/.claude/settings.json` 的 `skillOverrides.<skill name>`；四档映射为 `on` / `name-only` / `user-invocable-only` / `off`，nil 删除 key；非 nil 写入前后均经 `HostConfigReader` 读取用户级与全部项目级完整事实，项目 override 等更高优先级配置使有效档位无法达到主张时明确失败。`claimState(expecting:forSkillNamed:installations:)` 复用同一完整事实；`restoreConfiguration()` 恢复同文件单槽备份。Project settings 仍只读。
- `CodexConfigWriter.swift`：唯一 Codex 写 adapter 与 TOML/YAML 窄行级 parser owner。`apply(exposureLevel:forSkillNamed:installations:)` 把全禁用映射为匹配 `[[skills.config]] enabled = false`、仅显式映射为用户级 `~/.codex/agents/openai.yaml` 的 `policy.allow_implicit_invocation: false`（该用户级事实影响全部 Codex Skill），完全暴露删除两处对应配置；匹配现存 `path` 或旧式 `name`，新增条目只写 Codex Installation 的 as-found `SKILL.md` 绝对路径；保留目标行之外的未知字段、注释、空白、换行与其他条目。两个用户文件同动作预检/快照，按保守顺序提交；写后经 Reader 重读完整事实，无法达到主张时明确失败。`restoreConfiguration()` 一次恢复同一最近动作的两个用户级文件快照。永不写 Installation 或 Skill Source 内的 `agents/openai.yaml`。
- `PiVisibilityWriter.swift`：唯一 Pi 独占配置写 adapter。`apply(exposureLevel:forSkillNamed:)` 复用通用 Writer 的单槽备份与原子读改写 `~/.pi/agent/pagugu/visibility.json`；完全暴露从两个集合移除，`explicitOnly` 写 `hiddenSkills`，`fullyDisabled` 写 `disabledSkills`，`nameOnly` fail closed。`restoreConfiguration()` 恢复原字节或原本缺失状态。已存在文件无效时保留原字节并返回修复方向；零共享所有权冲突检测、零 Registry Claim。
- Claude Code JSON 只读 schema：顶层 `skillOverrides` 对象，key 为 Skill name，value 只接受 `on` / `name-only` / `user-invocable-only` / `off`。项目 settings URL 只从 Project Installation 的 `.../.claude/skills/...` 路径派生；项目 key 覆盖用户 key，不存在时继承用户值；同一 Skill Identity 进入多个 Installation 上下文时取最严格档位，避免假报更宽暴露。
- Pi 独占 JSON schema：顶层 `hiddenSkills` 与 `disabledSkills` 均为无重复非空字符串数组，两个集合必须互斥。前者派生 `explicitOnly`，后者派生 `fullyDisabled`，不存在的文件或未命中名称表示 `fullyExposed`；Pi 只把 `nameOnly` 呈现为 Unsupported。损坏文件在 Pagugu 侧读取与写入均 fail closed，Pi 扩展侧 fail open。
- Pi schema clean-break：#56 前的顶层 `skills` 仅是未发布只读占位，没有生产 writer、没有公开分发，也不是 ADR-0011 冻结的持久合同，因此无可迁移 canonical 状态；Reader 明确拒绝旧占位并呈现读取失败，不保留双 schema 路径。证据见 repo://docs/architecture/current-system-map.md「分发」与 repo://PaguguTests/HostConfigReaderTests.swift。
- Codex 兼容 `[[skills.config]]` 的 `path` 与现存旧式 `name` 标识；`enabled = false` 优先派生 `fullyDisabled`。`policy.allow_implicit_invocation = false` 派生 `explicitOnly`。Reader 与 Writer 共用 `CodexLineConfiguration`，避免读取与写入对同一窄 schema 产生两套解释。

反模式: Reader 不写宿主配置；通用 Writer 不决定 key 所有权、具体宿主档位映射或 TOML/YAML schema，不静默重应用 Registry Claim；Claude adapter 不写 Project settings；Codex adapter 不整文件重排、不写 Skill 内容；Pi adapter 不写 `settings.json`、不写 Skill 内容、不创建 Registry Claim；不把缺失文件当读取错误；不把已存在但不可读/损坏文件默认为完全暴露；不把 Unsupported 静默映射为相邻档位；不把读取结果或分歧状态存入 Registry 或缓存为第二真相；不在 JSON 核心中实现 TOML/YAML 解析器。

测试锚点: repo://PaguguTests/HostConfigReaderTests.swift（格式、默认值、能力缺口与 fail-closed）；repo://PaguguTests/HostConfigWriterTests.swift（通用提交、JSON 合并保全、缺失状态单槽备份、恢复与实时分歧）；repo://PaguguTests/ClaudeConfigWriterTests.swift（Claude 四档）；repo://PaguguTests/CodexConfigWriterTests.swift（Codex 三档、TOML/YAML 保格式、备份、漂移与分歧）；repo://PaguguTests/PiVisibilityWriterTests.swift（Pi 三档原子写、备份恢复与损坏保全）；repo://PaguguTests/AppModelSurfaceTests.swift、repo://PaguguTests/AppModelClaudeConflictTests.swift、repo://PaguguTests/AppModelCodexTests.swift（AppModel 实时聚合、完整事实冲突与动作）。
