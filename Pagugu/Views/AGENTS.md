# Views 模块合同（L2）

模块职责: 主窗口 Variant F IA 呈现（repo://docs/product/mvp-1.0-acceptance.md §2）。左侧平铺目录保持来源仓库行 + 子 Skill + 来源不明/失效映射行，显示 AppModel 给出的逐态状态短语与五档静默顺序。右侧 Skill 与来源不明详情呈现同名共存组徽标/逐宿主诊断，以及「调用面（Invocation Surface）」逐宿主当前档位、Unsupported 缺口与读取失败；Skill 详情的 Claude Code 行提供四档、Codex 行提供完全暴露/仅显式/全禁用三档主张切换，两者共用显著分歧警告、「重新应用主张」「采用磁盘配置」与逐宿主恢复；任一宿主配置读取失败时，即使 Registry 留有旧主张也禁用档位 Picker。Pi 行提供三档切换、单槽配置恢复、扩展缺失/不兼容修复指引与幂等「安装/更新 Pi 扩展」入口；扩展不健康时同时禁用档位与配置恢复，配置读取失败时禁用档位写入。Codex 的降级曝光 segment 禁用并同时显示 Unsupported 缺口；用户级「仅显式」明确标注会影响全部 Codex Skill，刷新后各条目仍按磁盘事实呈现。Skill 详情继续呈现「状态与检出」、安装位置、来源标识、SKILL.md 原文与「更新动作」；检出卡逐检出显示主状态、观察时间、检查结果、恢复方向与全部正交 Git Fact，不造来源级聚合状态。更新 intent 逐检出发起（仅 update-available 可用，其余禁用并给出原因），确认页列出精确计划与影响范围名单，多 Eligible 检出当次选择不持久化。结果区统一承载现有运行反馈、调用面失败与显著 Pi `/reload` / 重启提示，信息/警示/失败分级、可关闭。无仓库可归行逐 Installation 指定来源；映射目标 sheet 只列当前已发现 Skill，可筛选、不可自由输入；删除必须确认。工具栏提供唯一手动「检查更新」、进度/结果横幅、扫描范围管理与「最近活动」；Registry 故障全窗口阻断接管。全部 app-owned 界面固定浅色并使用暖米白品牌画布。只消费 Skill Read Model、只发 AppModel intent。

成员清单:
- `DesignTokens.swift`：主窗口视觉令牌唯一来源（品牌与暖米白全局画布、间距、圆角、尺寸、字号、语义状态色、表面材质、按压反馈）。目录、详情、结果区与 sheet 一律消费令牌；ChunUI 不引入（repo://docs/product/chunui-compatibility.md）。
- `ContentView.swift`：主从结构、暖米白根画布与窗口工具栏、四个透明系统滚动背景的 List、正式 Logo 欢迎引导、目录行、同名共存组只读诊断块、调用面块（Claude 四档与 Codex 三档 segmented Picker；Unsupported segment 与读取失败宿主写入口禁用；Codex 用户级「仅显式」披露对全部 Codex Skill 的影响；两宿主共用主张/磁盘分歧、重应用/采用磁盘和逐宿主恢复动作；Pi 三档 segmented Picker、单槽恢复、扩展健康/安装升级与 reload 提示）、逐检出卡片（含「更新…」intent）、宿主 logo 槽位、结果区（含调用面失败恢复方向）、更新确认 sheet（多检出当次选择 + 冻结计划确认）、扫描范围管理、受限恢复视图（「退出自行修复」只发 `AppModel.requestQuit`）与「最近活动」sheet（摘要列表 + 单条详情 + 清空确认；详情标注「当时记录」，失败不提供 stderr/命令复制/重试，只导航到相关 Skill；损坏呈现「历史不可用」；Registry 重置后呈现 quarantine 备份路径横幅）。
- `MenuBarView.swift`：暖米白状态栏窗口内提供打开主窗口与退出，不承载工作流（S12）。

反模式: View 不重建 HostProfile 冲突/能力规则、HostConfig 档位解析或分歧裁决；调用面写动作只发 AppModel intent，不直接改 Registry 或宿主文件；View 不做文件系统/Git/持久 IO，受限恢复「退出自行修复」不直接 `NSApplication.shared.terminate`，不裁决 Checkout Git State、Check Run 结果或重建目录排序；不引入分组标题与主目录筛选 UI；不按呈现组批量创建映射；不允许自由输入目标或无确认删除；frontmatter name 不同只警告、不阻断；行状态不聚合假状态；「相关记录」经工具栏「最近活动」承载、不建第二处详情块；受限恢复态必须全窗口阻断；历史呈现不冒充当前实时状态，失败详情不提供一键重试；不逐组件手写与 DesignTokens 冲突的间距/圆角/字号/状态色；不引入 ChunUI。
