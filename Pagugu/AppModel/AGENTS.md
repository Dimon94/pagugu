# AppModel 模块合同（L2）

模块职责: @MainActor composition root（ADR-0009 §7）。owns Skill Read Model 只读投影（含人工来源映射、目录逐检出状态短语、五档静默排序、同名共存组徽标与逐宿主诊断、调用面实时档位/主张/分歧/Unsupported/读取失败）、受限恢复与主张动作错误投影（RegistryRecovery / ProjectScanRootError / SourceMappingError / VisibilityClaimActionError）、Claude Code 档位切换/重应用/采用磁盘/单槽恢复的顺序编排、目录收起、App 级 Check/Update 单一互斥、Check Run/Update 瞬态与失败/取消投影、审计历史投影（auditHistory，只服务呈现）、全部 UI intent 唯一入口、启动与刷新流水线编排（Registry → Discovery → Git inspection → Identity → Eligibility）。每次发布经 HostConfigReader 重读宿主文件事实，并按 Registry Claim 实时派生分歧；按实时身份与 remote-tracking ref 重推导观察 freshness。失效成功观察保留在 Registry 但不投影观察时间。确认页取消或 Update Run 失败后，目标检出在本次 App 会话新的成功检查前不再消费旧观察，固定投影为 check-unknown。does not own 直接 Git/文件系统/持久 IO（经 HostConfig/Git/Registry/Audit/Discovery/Runs seam）或调用面协议解析、Checkout Git State/更新资格重建。

成员清单:
- `AppModel.swift`：公开入口含启动、刷新、全量手动检查、Update 检出候选/prepare/confirm/cancel、Project Scan Root 与来源映射创建/删除、Claude Code `setClaudeExposureLevel` / `reapplyClaudeVisibilityClaim` / `adoptClaudeDiskConfiguration` / `restoreClaudeConfiguration`、`clearAuditHistory(confirmed:)`、受限恢复 `requestQuit()`、审计失败详情导航解析 `skillIdentity(matchingSnapshotSourceKey:repositoryRelativePath:)`。Claude 切换顺序固定为同名配置键唯一性重查 → Registry durable claim → 用户级 settings 合并写 → 完整重读；同一归一化 name 命中其他 Claude Skill 时 fail closed，避免单身份主张影响多个身份；Registry 失败零宿主写入，配置失败保留主张并发布恢复方向；采用磁盘只删主张，恢复后保留主张并重新派生分歧。`activeRun` 是 App 级 Check/Update 互斥唯一真相，区分 preparing / awaiting-confirmation / executing / cancelling，并在每个首次 `await` 前原子转换；只有 awaiting-confirmation 可取消。检查与更新入口共用禁用原因。更新选择当次计算且不持久化；失败/取消清空 plan 并释放互斥；两者都标记目标检出需重新检查，新的成功检查才解除；成功先保留结果再独立完整刷新。post-verify facts 只作为该次刷新的一次性证据，需与刷新时 local-only 身份/HEAD/upstream/dirty/sibling 事实一致；不写 Observation、不跨刷新保留。公开只读投影含 `readModel`、调用面主张动作错误、Check Run 进度/汇总、冻结 `pendingUpdatePlan`、更新结果/刷新失败与 Registry 状态。Registry reset 成功后呈现 quarantine 备份路径（registryResetBackupPath，一次性可关闭）。
- `SkillReadModel.swift`：`SkillReadModel`（目录、映射、扫描、Project Scan Root、逐来源检出卡片、目录状态短语与排序、逐 Skill/来源不明条目的同名共存组及调用面只读投影）、`NameCollisionReadModel`、`CheckoutCardReadModel`（观察与本次检查投影）、目录节点与选择解析入口。同名共存组与调用面只读投影都不改变身份、Git 状态或更新资格。
- `RegistryResetting`：AppModel 内部 reset seam。生产只由 `AppRegistry` 实现；测试注入取消或未分类失败，穿过 `resetRegistry(confirmed:)` 验证稳定投影。

反模式: View 不绕过 AppModel 直接 IO、直接 terminate 或重建业务规则；AppModel 不解析 Host 配置/Git 输出或复制 HostProfile/Eligibility 规则；不自动重应用主张，不把分歧写入 Registry；不以多个布尔值或 Runs 内锁复制 `activeRun`；收起状态、run 瞬态、Host 配置事实与 Git Fact 不持久化；投影不反向成为第二真相；受限恢复态不制造内存 fallback。

测试锚点: repo://PaguguTests/AppModelTests.swift（Registry gate、requestQuit 退出 intent、Project Scan Root intent、目录状态短语/排序表、Check Run 投影与 intent 路由 smoke、取消或更新失败后 fresh 旧观察不再解锁更新；全部用构造注入的临时 Persistence 目录）；repo://PaguguTests/AppModelCollisionTests.swift（同名异源保持独立身份并发布只读诊断）；repo://PaguguTests/AppModelSurfaceTests.swift（调用面文件事实实时聚合与刷新）；repo://PaguguTests/AppModelClaudeConflictTests.swift（Claude 切换、外部修改分歧、重应用、采用磁盘、恢复与写失败）；repo://PaguguTests/PaguguTests.swift（ContentView 退出不直接 terminate）。
